# eSCIENCES · education

Applications pédagogiques interactives créées pour [eSCIENCES.be](https://www.esciences.be).

Chaque application tient dans un seul fichier `index.html` : elle s’ouvre directement dans un navigateur, fonctionne sans connexion, sans installation et sans compte.

## Applications

| Discipline | Application | Public | En ligne |
|---|---|---|---|
| Français | **Chronique · Atelier du passé simple** : former et employer le passé simple (128 questions, 7 chapitres, correction en deux essais) | 3e secondaire | [Ouvrir](https://esciences.github.io/education/francais/passe-simple/) |

## Organisation du dépôt

Un dossier par discipline, puis un dossier par application :

```
education/
├── francais/
│   └── passe-simple/
│       └── index.html
├── README.md
└── LICENSE
```

## Utilisation en classe

- **En ligne** : partager le lien de la colonne « En ligne » (GitHub Pages).
- **Hors ligne** : télécharger le fichier `index.html` et l’ouvrir dans un navigateur.

La progression des élèves reste enregistrée dans leur navigateur (localStorage). Aucune donnée n’est envoyée.
